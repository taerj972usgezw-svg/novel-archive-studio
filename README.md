# 📖 소설 아카이브 스튜디오 (Novel Archive Studio)
> **공식 도메인**: [소설.메인.한국](http://소설.메인.한국) (`xn--9t4b11e.xn--f12ba.xn--3e0b707e`)  
> **배포 타겟**: Railway Cloud Container (`https://*.up.railway.app`)

---

## 🌟 프로젝트 소개
웹소설 작가가 자유롭게 작품을 등록하고, 회차별로 집필/연재/수정하며 영구 보관할 수 있는 올인원 웹소설 플랫폼 및 작가 스튜디오입니다.

독자는 **1화부터 첫편 정주행**, 몰입형 뷰어, **TTS 오디오북 음성 읽기**, **독서 앰비언스 BGM(빗소리/모닥불/하프)**, **텍스트(.txt) 소장 다운로드**, 서재 이어보기 등 32가지 이상의 프리미엄 기능을 이용할 수 있습니다.

---

## ✨ 탑재된 핵심 기능 (32가지)
1. **작품 등록 & 관리**: 제목, 작가명, 장르(판타지/로판/무협/현판/SF/미스터리), 시놉시스, 연재상태 설정
2. **표지 커버 프리셋**: 장르별 6종 고화질 커버 프리셋 및 맞춤 배지
3. **스마트 회차 에디터**: 회차 자동 카운팅, 실시간 글자수(공백포함/제외), 예상 완독 시간 계산
4. **원클릭 1화 정주행**: 소설 카드 및 상세 페이지에서 1화 즉시 진입
5. **이전화/다음화 스마트 네비게이터**: 상하단 플로팅 네비게이션 및 키보드 단축키(좌우 화살표)
6. **목차(TOC) 모달**: 독서 중 어디서나 전체 회차 확인 및 점프
7. **리더 커스텀 폰트 4종**: KoPub 바탕(명조), 프리텐다드(고딕), 나눔명조, 나눔고딕
8. **글자 크기 미세 조절**: 14px ~ 28px 슬라이더 및 A-/A+ 버튼
9. **줄간격 및 자간 조절**: 1.4배 ~ 2.6배 여백 최적화
10. **4색 독서 테마**: 라이트(화이트), 세피아(아이보리), 다크(차콜), OLED(완전 블랙)
11. **뷰어 너비 조절**: 슬림(600px), 보통(740px), 와이드(880px)
12. **독서 진행률 게이지**: 상단 실시간 0~100% 프로그레스 바
13. **전체화면 몰입 모드**: 풀스크린 토글
14. **독서/집필 앰비언스 BGM**: 창가 빗소리, 서재 모닥불, 판타지 하프 선율 (Web Audio API 신디사이저)
15. **TTS 오디오북 모드**: Web Speech API 기반 한국어 음성 낭독
16. **작가의 말 카드**: 회차별 작가 후기 분리 카드
17. **회차 추천/좋아요**: 실시간 하트 카운터
18. **회차별 독자 댓글**: 닉네임 댓글 작성 및 실시간 목록
19. **내 서재 (이어보기)**: 최근 읽은 작품, 마지막 회차 자동 기억 및 원클릭 이어보기
20. **텍스트(.txt) 소장 다운로드**: 회차별 or 전편 텍스트 파일 원클릭 내보내기
21. **작가 수정 비밀번호 보호**: 작품 및 회차 무단 수정/삭제 방지 보안
22. **자동 임시저장(Auto-Save)**: 집필 중 15초마다 자동 로컬 백업
23. **장르 & 실시간 검색**: 제목/작가/줄거리 실시간 필터링
24. **정렬 필터**: 최신순, 조회수순, 추천순 정렬
25. **작가 집필 통계 인포그래픽**: 총 작품수, 총 회차, 총 글자수, 누적 독자수
26. **키보드 단축키**: 이전화(←), 다음화(→), 목차(M)
27. **SNS & 링크 공유**: 카카오톡, X(트위터), URL 클립보드 복사
28. **도메인 웹포워딩 감지**: `소설.메인.한국` 트래픽 감지 및 웰컴 배너
29. **실시간 텔레메트리**: IP, 통신망(4G/WiFi), GPU 그래픽, CPU 코어, RAM, 화면 해상도, 터치포인트 수집
30. **디스코드 실시간 웹훅**: 신규(🔴) vs 재방문(🔵) 구분 임베드 알림 (3분 쿨다운)
31. **1초 간편 독자 등록**: 가짜 SMS 인증 대기 없이 휴대폰 번호 즉시 등록
32. **최고 관리자 관제탑**: 회원 DB 12개 컬럼 실시간 테이블, **📥 엑셀(CSV UTF-8 BOM) 원클릭 다운로드**

## 🚀 로컬 실행 방법
```bash
# 의존성 설치 (최초 1회)
npm install

# 서버 실행 (포트: 8085)
npm start
```
또는 `start.bat`을 더블 클릭하여 실행합니다.
